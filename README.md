# Python for Astronomy Workshops & Student Labs

A curated collection of interactive Jupyter Notebooks and guided lab exercises developed by **Dr. Ravi Raja Pothineni** for undergraduate Value-Added Courses (St. Joseph's Degree & PG College, Bhavan's Vivekananda Degree College), **Indian Space School**, and **ASTRO** training programmes.

Built for school students, undergraduates, and aspiring researchers learning computational astronomy from the ground up, each notebook pairs step-by-step code with clear physical intuition so learners see how raw astronomical data turns into astrophysical measurements.

## What Is Inside
- **CCD Image Inspection & Aperture Photometry (`notebooks/01_fits_inspection_and_aperture_photometry.ipynb`):** Covers 2D image arrays, background/sky estimation, radial point-spread profiles, circular aperture photometry, and instrumental magnitude calculation.
- **Exoplanet Transits & Time-Series Analysis (`notebooks/02_exoplanet_transit_and_ztf_timeseries.ipynb`):** Introduces light-curve cleaning, period folding, transit depth estimation ($R_p / R_\star$), and multi-epoch variability exploration inspired by student research and summer school projects (such as exoplanet transits and stellar streams).
- **Workshop Exercises & Guided Prompts:** Structured checkpoints for instructors and self-learners to test assumptions, inspect noise sources, and interpret plots rather than treating code as a black box.

## Who This Is For
- Undergraduate and postgraduate astronomy/physics students taking introductory data-analysis or value-added courses.
- Summer/winter school participants and astronomy club mentors running practical Python sessions.
- Selection and evaluation committees (such as HBCSE-TIFR) looking for concrete evidence of inquiry-driven pedagogy and student mentorship.

## Stack & Usage
Designed around standard Python scientific libraries (`numpy`, `scipy`, `matplotlib`, `astropy`) so notebooks run cleanly in local environments, VS Code, or Google Colab without heavy setup overhead.
